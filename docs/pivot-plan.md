개별 설정의 문제가 아니라 **SFT라는 방법 자체가 이 베이스 모델과 맞지 않는다**는 구조적 신호.

## 진단 (왜 SFT가 항상 해로운가)

Qwen2.5-3B-Instruct는 이미 대규모 SFT+RLHF로 정밀 조율된 모델이다 (GSM8K ~80%).
여기에 우리 규모(수만 건)의 SFT를 얹으면:
1. **기존 조율의 파괴**: 어떤 데이터든 원래의 정제된 출력 분포를 흐트러뜨림 (catastrophic forgetting) — 얻는 것보다 잃는 것이 큼
2. **다양성 붕괴**: SFT는 출력을 학습 데이터 쪽으로 수렴시킴 → SC 다수결의 재료(서로 다른 풀이 경로)가 줄어 SC 점수가 greedy보다 더 크게 하락 (exp09b에서 SC -2.9%p로 최대 하락이 그 증거)
3. 반면 **추론 시점 기법은 전부 성공**: SC +5.3%p, n스케일 +0.9%p, 가중투표 +0.8%p — 베이스의 능력을 건드리지 않고 뽑아내는 방법만 통해 왔다

## 전환 방향 (2트랙)

### 트랙 A — 학습 패러다임 교체: GRPO 강화학습 (H17, 주력)

SFT의 실패 원인을 정면으로 회피하는 유일한 학습 방식:
- **KL 제약**이 베이스 정책 근처를 벗어나지 못하게 묶음 → "기존 조율 파괴" 원천 차단
- 정답 보상만 주고 풀이 방식은 자유 → **다양성을 죽이지 않음**
- 모방(SFT)이 아니라 결과 최적화 → 우리 지표(Exact Match)를 직접 올림
- 근거: DeepSeekMath(arXiv:2402.03300) — 이미 강한 모델을 GRPO로 추가 향상시킨 선례
- 실행: `remote/train_grpo.py` (파일럿: 중간 난이도 문제 3천 개, 소규모 스텝) → 검증 평가
- 성공 기준: SC n8 ≥ 75.7% (베이스 +1%p). 파일럿 성공 시 스케일업, 실패 시 학습 트랙 전면 동결

### 트랙 B — 추론 파이프라인 재설계 (병행, 저비용)

학습 없이 검증된 이득을 쌓는다 (성공 확률 높음):
- **B1. 최적 스택 확정**: SC n=16 + 가중투표 조합 측정 (개별 이득 합산 시 ~76.5% 기대)
- **B2. 프롬프트 앙상블** (H19): SC 표본을 서로 다른 시스템 프롬프트(대수적/검산 강조/간결 등)로 생성해
  다양성을 인위적으로 확대 — SFT가 죽이던 다양성을 반대로 늘리는 발상
- **B3. 2단계 자기수정** (H18): 1차 풀이 → 같은 모델에게 "검토·수정" 프롬프트로 2차 → 최종 답
  (모델 출력만 사용하므로 규칙 적합)

## 성공/철수 기준

- 트랙 A 파일럿이 베이스 +1%p 미만이면: **학습 트랙 완전 동결**, 남은 기간 추론 최적화 + 검증자/앙상블(H8·H9, 운영진 답변 대기)에 집중
- 트랙 B는 각 항목 +0.5%p 이상이면 최종 스택에 채택
- 최종 목표 경로: 베이스 74.7% → B스택 ~77% → A성공 시 +α → 검증자(H9 허용 시) ~80%+
