급상승 구간과 그 이유

아직 상승 구간이 없습니다. 실험 2개 이상부터 표시됩니다.

무엇이 통했고, 무엇이 통하지 않았나

✓ 채택 (기준선 대비 개선) ~ 노이즈 (±1%p) ✗ 하락 pass@6 상한 79.9%

모든 수치는 동일한 검증 483문항 기준. pass@6 = 79.9%는 "6번 풀면 정답이 한 번은 나오는" 비율로, 집계 방식만으로 회수 가능한 이론적 상한 — 실제 최고치(75.8%)와의 4.1%p 갭이 검증자·가중투표가 노렸으나 열지 못한 구간이다.

가설 백로그

가설내용기대상태
H1max 토큰 2048 + 소수점-안전 답 추출+2~4%p✅ 적용됨 (exp05에 포함)
H2Self-Consistency n=8 다수결+5~10%p✅ 확인: +5.3%p (exp05, 69.4→74.7%)
H3RFT: 자체 생성 풀이 중 정답만 QLoRA SFT+5~15%p❌ 1차 실패 (exp06 −1.2%p, 과적합·자기증류 한계) → 🔄 exp06c 완만 재시도 (lr↓, 최단풀이=H14)
H4NuminaMath-CoT 등 공개 CoT 데이터 혼합+3~8%p대기 (H12로 구체화)
H5TIR: 모델이 쓴 파이썬 실행으로 계산 보조–❌ 금지 (운영진 Q&A: 추론 시 코드 실행·툴 호출 불허)
H6양자화+vLLM (SC 샘플 수 확대용 속도)간접병목 시
H7GRPO 강화학습불확실후순위
H8멀티 LoRA 어댑터 앙상블 (같은 베이스, 다수결)+2~5%p⏳ 운영진 질의 중
H9검증자 어댑터로 Best-of-N 선별+3~8%p⏳ 운영진 질의 중
H10반복 RFT (학습된 모델로 재생성)+3~8%p⏭️ 스킵 — 전제(개선된 어댑터) 미충족
H11SC 샘플 수 스케일링+1~4%p✅ n=16 75.6% (+0.9%p vs n8), 수확 체감
H12NuminaMath 외부 데이터 혼합 학습+3~8%p🔄 실행 중 (exp09a·b) — 실패 시 정체 3/3
H14최단 풀이 학습+1~4%p❌ 효과 없음 (exp06c)
H16확신도(로그확률) 가중 투표+1~3%p⚠️ 불안정 (exp10 +0.8 → exp11 -0.4, 노이즈 범위) — 채택 보류
H17GRPO 강화학습 (KL 제약 RL)+2~5%p❌ 파일럿 베이스와 동일 (exp12) → 학습 트랙 동결
H182단계 자기수정+1~3%p❌ 노이즈 범위 (exp15)
H19프롬프트 앙상블 SC+1~3%p❌ 노이즈 범위 (exp14)

참고 자료 (auto-research)

  • How NuminaMath Won the 1st AIMO Progress Prize (Hugging Face 블로그) · 코드
    우리와 동일한 Kaggle T4×2 환경의 수학 대회 우승 솔루션. SC-TIR(다수결+파이썬 실행), T4용 GPTQ 8bit 양자화 → H2·H5·H6의 근거
  • Wang et al., Self-Consistency Improves Chain of Thought Reasoning in Language Models (ICLR 2023, arXiv:2203.11171)
    다수결(SC)의 원 논문. GSM8K +17.9%p 사례 → H2의 근거
  • Yuan et al., Scaling Relationship on Learning Mathematical Reasoning (RFT, arXiv:2308.01825)
    정답에 도달한 자체 생성 풀이만 골라 SFT(Rejection Sampling FT). 소형 모델에서 효과 큼 → H3의 근거. STaR(arXiv:2203.14465)도 동계열 · 개념 정리
  • AI-MO/NuminaMath-CoT · nvidia/OpenMathInstruct-2
    풀이 과정이 달린 무료 공개 데이터셋 86만/1,400만 쌍 (Apache 2.0 등) → H4의 재료. 사용 시 README 데이터 목록에 기재
  • AIMO-2 우승 솔루션 (arXiv:2504.16891) · AIMO-3 분석 (arXiv:2603.27844)
    추론 시점 기법보다 모델 학습이 지배적 → SC 다음은 SFT가 본게임이라는 우선순위의 근거
  • AIMO-3 writeup: Entropy-Weighted Self-Consistency
    SC 개량 변형 — n을 키운 뒤 시도할 후보
  • Qwen2.5-3B-Instruct 성능 정리 · Qwen2.5-Math 블로그
    베이스 모델의 GSM8K ~83% 참고치 (우리 66%는 경시형 48% 혼합 탓). Math 모델 자체는 규칙상 사용 불가, 학습 방법론만 참고
  • Small Models Struggle to Learn from Strong Reasoners (ACL 2025)
    소형 모델은 지나치게 길고 어려운 풀이로 학습하면 역효과 → SFT 데이터 선별 시 풀이 길이 관리
